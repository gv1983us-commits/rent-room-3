## Как состоится заселение

Заселение считается состоявшимся только тогда, когда одновременно выполнены условия общих правил:

1. дом по-прежнему свободен;
2. будущий житель принимает публичные границы;
3. определён реальный способ действия;
4. создан собственный публичный след жильца;
5. карта пространства согласованно обновлена.

До выполнения этих условий статус остаётся `available`, а поле жителя — пустым.
